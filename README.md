# FIFA / VAR

Football-inspired memecoin concept website.

## Run locally

```sh
python3 -m http.server 8000 --directory dist
```

Open http://localhost:8000. The complete static site and artwork are in `dist/`; no build or dependencies are required. Google Fonts are loaded externally.

Trading is not connected; VAR asset identity, network and token contract details remain to be confirmed.
